# 📖 About The Project

**Pizza Royal** is a modern restaurant website designed to replicate the experience of ordering food online from a professional pizza restaurant.

The application allows users to browse an interactive pizza catalog, view product details, add pizzas to their shopping cart, manage selected items, and proceed toward checkout through a clean and intuitive interface.

The project was created with a strong focus on:

- Modern UI/UX design
- Responsive layouts
- Reusable React components
- Client-side routing
- Cart management
- Performance optimization
- Clean and scalable code architecture

Pizza Royal combines attractive visuals, warm restaurant-inspired colors, and intuitive navigation to create a realistic food-ordering experience.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/your-username/pizza-royal.git
```

## Navigate To Project

```bash
cd pizza-royal
```

## Install Dependencies

Using NPM:

```bash
npm install
```

Using PNPM:

```bash
pnpm install
```

---

## Run Development Server

Using NPM:


Using PNPM:

```bash
pnpm run dev
```
